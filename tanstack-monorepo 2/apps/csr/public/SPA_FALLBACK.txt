Deploying the CSR build (apps/csr/dist) to a static host requires an SPA fallback
so deep links like /posts/2 serve index.html. Examples:
  Netlify  -> public/_redirects:   /*  /index.html  200
  Vercel   -> vercel.json:         { "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }
  nginx    -> try_files $uri /index.html;
